# 出口景气后端规则

后端实现见 `src/export_confidence.py`，测试见 `tests/test_export_confidence.py`。
后端只依赖标准库，状态保存在仅追加事件日志 `events.jsonl`，任何时刻可完整回放。

## 角色

| 角色 | 职责 |
| --- | --- |
| 统计人员 statistician | 建轮次、锁框、录入/导入、提出预测调整、推进发布 |
| 数据复核人员 reviewer | 确认预测调整（须为另一个人），可查看匿名答卷与核对区 |
| 报告审批人员 approver | 查询联表报告并复算 |
| 行业协会 association | 提交依据；只看自己的依据与已发布报告，看不到任何答卷 |
| 出口企业 enterprise | 只能替本企业业务单元提交答卷 |

## 轮次、样本框与水位

1. 统计人员创建发布轮次（期次、记账币种）。
2. **期开始前**锁定样本框：合格企业/业务单元、企业权重、好淡分界（0–100）。
   锁框后与轮次开始后均不得再改。
3. 同一企业拆成多个业务单元时，各单元按份额 `share` 计权，同企业份额合计
   不得超过 1——拆分不能重复占权重。指数计算权重 = 企业权重 × 份额。
4. 轮次内顺序打开“水位”（level）。数据只写入尚未发布的水位；已确认水位不可变。
5. 补报（答卷或贸易批次）若指向已确认水位，自动转入当前未发布水位，并标记
   `late`；没有未发布水位时必须先打开新水位。
6. 每业务单元每水位至多一份答卷；同一提交编号或同一批次编号重放为幂等，
   不产生第二份样本；编号相同而内容不同则拒绝。

## 企业调查

- 现状与预期回答均为 0–100 的分值，严格大于好淡分界才算“好”。
- 置信指数取各已确认水位中每业务单元的最新一份答卷，按份额权重汇总
  出现状指数与预期指数。
- 不合格单元不能答卷；企业角色只能替本企业单元答卷。

## 贸易批次与核对区

- 批次必须属于锁框内的合格企业/业务单元、已登记商品，件数单位、重量单位
  （KGM）、币种（轮次记账币种）必须一致。
- 任一不一致的行进入核对区（quarantine），**只滞留该行**，同批其他品类照常入库。
- 更正核对区记录时不能改批次编号；原水位已确认的，更正数据进入未发布水位。

## 预测情景与双角色确认

- 统计人员提出调整：情景、增长区间（下限≤上限）、**推动因素、相反信号、
  适用期限（起止）**，三要素缺一不可，可引用协会依据。
- 必须由**另一个人**（复核人员角色）逐项复述确认三要素与提案完全一致；
  同一人不能既提又确认，协会无权确认。
- 未经确认不得开始发布。

## 发布与崩溃恢复

- 发布流程：开始发布 → 水位按序确认 → 全部确认后完成发布。
- 水位确认必须按序号推进；重复确认与重复开始发布均为幂等。
- 进程在任意时刻终止后，重建 `Store` 即从日志恢复：`recovery_point`
  返回已确认水位与下一个待确认水位，从断点继续；已确认水位不会重放或回退。

## 报告查询与最小披露

`build_report` 仅基于已确认水位，把以下内容联在一份报告里：

- 增长区间、情景、适用期限、提出/确认角色；
- 现状与预期置信指数（含好淡分界、覆盖权重、应答企业数）；
- 主要市场的货值、份额与对总增速的贡献百分点；
- 高价值货品的货值、份额、贡献百分点，以及件数/重量/货值三项增速，
  使“件数、重量与货值给出相反信号”可被直接复核；
- 复算块：记账币种、本期与上期总货值、观测增速、纳入水位、
  已接受批次数与核对区滞留行数。

报告不含企业或批次标识；分组内企业少于 3 家，或最大企业货值占比 ≥ 60% 时，
该组并入“其他（最小披露合并）”。协会只能查看已发布报告。
