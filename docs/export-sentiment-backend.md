# 出口景气后端设计

按发布轮次组织企业调查（现状与预期回答）、商品层级、贸易批次与预测情景，
解释高价值商品增长区间的市场与品类来源。

## 轮次状态机

筹备 → 收集 → 截止 → 发布中 → 已发布

- 筹备：登记样本框草稿（资格、原始权重、好淡分界）。
- 锁定样本框后进入收集：业务单元权重按企业配额归一。
- 截止后只接受补报；发布中与已发布拒绝一切补报与批次导入。
- 发布按 FREEZE → INDEX → ATTRIBUTION → REPORT 顺序确认水位，
  意外终止后用同一 Store 重建服务即可从已确认水位恢复。

## 不变量

1. 样本框锁定后，资格、权重与好淡分界不可再改。
2. 同一企业各业务单元权重之和恒等于企业配额，拆分不会重复计权。
3. 补报与核对放行只能进入尚未发布的水位。
4. 批次按批次号幂等；同号不同内容视为异常，拒绝导入。
5. 单位或币种不一致的批次行停在核对区，不进入任何聚合，不影响其他品类。
6. 预测调整由统计人员提出、另一角色确认；推动因素、相反信号与适用期限缺一不可。
7. 行业协会可提交依据，但看不到其他匿名答卷，也只能看到自己提交的依据。
8. 报告只含聚合结果；少于 3 家企业的分布单元必须合并；不足 3 家企业不得发布。

## 模块

- `models.py` 实体与值对象
- `store.py` 内存持久层（水位落在此处，支持恢复）
- `rounds.py` 轮次与样本框锁定
- `survey.py` 答卷与补报
- `intake.py` 批次导入与核对区
- `evidence.py` 协会依据与可见性
- `forecast.py` 预测情景双人确认
- `computations.py` 指数与归因纯函数（发布与复核共用）
- `publishing.py` 水位发布与恢复
- `reporting.py` 报告查询与复核

## 报告联通视图

`ReportService.report` 把已确认情景的增长区间与适用期限、现状与预期置信指数
（含好淡分界判定）、主要市场贡献与高价值货品贡献放在同一份报告中；
审计段提供复算所需的聚合原料（权重合计、加权得分、基期与现期货值），
审核者可用 `recompute_indices` 重算指数并与发布值核对，
全程不暴露单家企业。
