# 高价值电子出口景气归因

归集出口调查、贸易批次和预测情景，解释高价值商品增长来源。

## 参与方与事实

主要参与方包括贸易发展研究人员、行业协会、出口企业、数据复核人员、报告审批人员。领域资料记录以下已经确认的事实：

- 香港上调2026年商品出口货值增长预测至42%至47%
- 电子产品成为主要增长动力
- 现状与预期指数均高于50

## 业务约束

- 样本资格与权重
- 商品层级与单位
- 指数发布
- 预测情景
- 证据归因

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/news_context_002.py` 负责读取和校验这些资料。

## 出口景气后端

`src/export_sentiment/` 按发布轮次组织企业调查、商品层级、贸易批次与预测情景：

- 每期开始前锁定样本资格、权重与好淡分界；同一企业的业务单元权重归一到企业配额，拆分不会重复计权
- 补报数据只能进入尚未发布的水位；重送相同批次不会产生第二份样本
- 单位或币种不一致的批次行停在核对区，由数据复核人员更正或退回，不影响其他品类
- 统计人员提出预测调整，报告审批人员确认推动因素、相反信号与适用期限后生效
- 行业协会可提交依据，但看不到其他匿名答卷
- 发布按水位推进，意外终止后从已确认水位恢复
- 报告查询联通增长区间、置信指数、主要市场与高价值货品贡献，审核者可复算且不暴露单家企业

设计细节见 `docs/export-sentiment-backend.md`。
