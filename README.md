# 高价值电子出口景气归因

归集出口调查、贸易批次和预测情景，解释高价值商品增长来源。

## 参与方与事实

主要参与方包括贸易发展研究人员、行业协会、出口企业、数据复核人员、报告审批人员。领域资料记录以下已经确认的事实：

- 香港上调2026年商品出口货值增长预测至42%至47%
- 电子产品成为主要增长动力
- 现状与预期指数均高于50

## 业务约束

- 样本资格与权重
- 商品层级与单位
- 指数发布
- 预测情景
- 证据归因

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/news_context_002.py` 负责读取和校验这些资料。

## 出口景气后端

`src/export_confidence.py` 实现出口景气后端：按发布轮次组织企业调查（现状与预期）、
商品层级、贸易批次与预测情景，规则详见 `docs/backend-rules.md`。要点：

- 期开始前锁定样本资格、权重与好淡分界；业务单元按份额计权，拆分不重复占权重；
- 数据按水位累积，补报只能进入未发布水位；批次与答卷幂等；
- 单位或币种不一致的行停在核对区，不影响其他品类；
- 协会只交依据、不看答卷；预测调整须统计人员提出、另一角色逐项确认
  推动因素、相反信号与适用期限；
- 事件日志可回放，发布中断后从已确认水位恢复；
- 报告联表增长区间、置信指数、主要市场与高价值货品贡献，含复算块，
  经最小披露压制，不暴露单家企业。
