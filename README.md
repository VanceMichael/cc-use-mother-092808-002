# 高价值电子出口景气归因

归集出口调查、贸易批次和预测情景，解释高价值商品增长来源。

## 参与方与事实

主要参与方包括贸易发展研究人员、行业协会、出口企业、数据复核人员、报告审批人员。领域资料记录以下已经确认的事实：

- 香港上调2026年商品出口货值增长预测至42%至47%
- 电子产品成为主要增长动力
- 现状与预期指数均高于50

## 业务约束

- 样本资格与权重
- 商品层级与单位
- 指数发布
- 预测情景
- 证据归因

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/news_context_002.py` 负责读取和校验这些资料。

## 开发命令

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```
